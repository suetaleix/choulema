# V8 第二轮 UI 优化

用户已确认八项全部优化；先本地体验，确认后才部署。

1. 舞台：默认/星空三机台适度放大，按安全区域取景；不裁切机台或结果，不改已确认几何与音效。背景中心适度提亮。
2. 控件：画质与简洁动效留在偏好面板；舞台常驻声音、全屏；图标风格统一。
3. 字体：主操作约 14px，辅助文字约 12px，增强对比，触摸目标不少于 44px。
4. 主题：根据当前机台对比两套真实外观，仍读取服务端价格和权益，预览结束恢复原轮次。
5. 登录：三台真实机台手动切换，不自动轮播；体验按钮带入选择。已登录用户显示当前账号的最近玩法，紧凑呈现，不读取其他账号草稿。
6. 手机：竖屏常用工具集中在底部；候选用底部展开面板，内容独立滚动，应用/保存固定；横屏单独布局。
7. 结果：金色标题，主按钮再抽一次；复制与收起降低视觉权重；长名字、多结果、分组可滚动或分页。
8. 后台：待处理事项在概览前部，点击进入对应筛选；统计口径按需展开，保留浅色工作台。

验收要求：桌面、平板、手机竖屏及短横屏实测；覆盖三机台两主题、默认最高画质、空格抽取、结果/设置、返回玩法、主题预览及账号/后台入口。自动测试与浏览器证据分开记录。当前仅本地开发，不进行真实付款或生产部署。


## 实施与本地验收（2026-10-07）

上述八项已接入 8911 本地环境，等待用户体验确认。沿用第一轮独立数据库、测试账号及销售关闭状态；未部署生产。

- 三机台两主题按可用舞台区域适度放大，取景上限保留边界，完整演出保持原有取景；背景中心提亮。已确认的机台几何、材质和音效素材未重做。
- 主舞台隐藏画质/简洁动效开关，集中在演出偏好，默认仍为最高画质和完整动效。工具图标、字体、辅助文字和弹层按钮颜色统一。
- 六张真实机台截图用于当前机台的默认/星空外观比较，不再全都展示转盘。两个主题仍分别提供三种已确认音效。
- 登录页新增胶囊、转盘、姓名星球手动预览，体验链接带入对应机台；已登录用户显示本账号最近玩法及配置名称。当前账号无草稿时显示通用入口。
- 手机工具栏集中底部；候选设置为底部展开面板，表单滚动与应用/保存操作区分离；横屏单独排列。修复浏览器验收中发现的旧样式覆盖、工具栏宽度和短屏声音按钮与玩法栏重叠。
- 结果金色标题和主要动作更突出，保留复制/返回；多结果、分组与长姓名可查看。分组后的“新一轮分组”继续保留原有确认和历史记录。
- 后台待处理事项移到指标前，已付未开通、退款待确认、部分退款待复核、邀请待核验直接进入相应筛选；统计口径折叠显示。概览增加有效星空皮肤数，避免重复展示同一异常数字。
