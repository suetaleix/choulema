## 4. 在新电脑本地启动

准备 Python 3.11 或以上。进入解压后的 `lottery-platform` 文件夹，Windows PowerShell 运行：

```powershell
.\scripts\start_v8.ps1
```

首次自动建立虚拟环境并安装运行依赖，需要联网。默认打开 `http://127.0.0.1:8908/login.html`。若端口已占用：

```powershell
.\scripts\start_v8.ps1 -Port 8912
```

首次需要本地管理员可加 `-Admin`，按提示输入初始化信息，之后用账号 ID `localadmin` 登录；该内部兼容初始化仍要求输入手机号，不是用户注册界面的必填项。包内没有预建账号或固定管理员密码。不要拿本地测试账号直接用于生产。

本地新库位于 `data/v8-local.sqlite`，不会连接原站数据库，在线销售默认关闭。Linux/macOS 安装 `requirements.txt` 后执行 `python scripts/start_local.py`。`-Check` / `--check` 只检查依赖与版本，不创建数据库。

## 5. 启用邮箱注册

未配置邮箱时，免费体验和已有账号登录正常，新注册发码不可用。复制 `deploy/mail.example.json` 到私密目录，填写发件邮箱并把邮箱提供商的 SMTP 授权码保存到独立文本文件；在 JSON 的 `password_file` 写该文件绝对路径。

```powershell
.\scripts\start_v8.ps1 -MailConfig 'C:\private\choulema-mail.json'
```

配置只在服务端加载，不要放进 `static/`。本地启动器不会自动加载 `.env.example` 或继承生产邮箱配置。服务器用 `LOTTERY_MAIL_CONFIG_FILE` 指向私密 JSON，详见部署指南。QQ/foxmail 可按已验证的本地配置使用 `smtp.qq.com`、465、`ssl`，实际用户名和授权码需在目标机器单独配置。

## 6. 安装服务器或升级原站

1. 先完成本地体验与真实邮箱收码验收。
2. 解压部署包到新的版本目录，安装固定运行依赖；不要直接覆盖正在运行的代码。
3. 首次部署参考 `deploy/production.env.example`、`deploy/lottery.service`；已有站点沿用现有域名、数据库、支付宝、卡密密钥和备份配置，只增补邮箱配置。
4. 维护窗口停服，确认库无其他写入者。运行迁移命令，`--output` 必须是不存在的新路径：

```text
python scripts/manage_db.py migrate --database /var/lib/choulema/lottery.sqlite --output /var/backups/choulema/before-email-唯一时间.sqlite
```

5. 本次邮箱版有数据库结构变更：手机号改为可空、新增唯一邮箱/验证时间及验证码/限流表。工具先备份，再检查原记录保留与完整性。失败时不要继续切换。
6. 切换代码并启动，验证健康、邮件、注册与登录、一次完整抽取、超管、已有权益及历史订单，之后再结束维护。
7. 保留旧版本与备份。产生邮箱账号后，回退代码也必须支持邮箱登录；直接恢复旧数据库会丢失备份之后的业务，需要先对账。

服务使用单进程 Uvicorn + SQLite，HTTPS 反向代理只转发到回环地址，不把代码目录直接暴露为静态站点。配置示例不是可直接照抄的真实生产配置。生产安装的详细步骤以部署指南为准。
