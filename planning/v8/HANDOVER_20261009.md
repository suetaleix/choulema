## 新电脑本地启动

安装 Python 3.11 或以上，进入解压后的 `lottery-platform` 目录，Windows PowerShell 运行：

```powershell
.\scripts\start_v8.ps1
```

首次自动创建虚拟环境并安装固定依赖，需要联网。默认地址 `http://127.0.0.1:8908/login.html`；端口占用时加 `-Port 8912`。

首次初始化本地超管使用 `-Admin`，交互输入内部兼容手机号与至少 10 位密码，之后以账号 ID `localadmin` 登录；不会重置已有超管。用户注册界面不需要手机号。包内没有预设账号、测试数据库或固定生产密码。

Linux/macOS：建立虚拟环境，安装 `requirements.txt`，再运行 `python scripts/start_local.py`。`--check` / `-Check` 只检查，不创建数据库。本地运行会使用独立的 `data/v8-local.sqlite`，关闭在线销售，不继承生产商户配置。

## 邮箱注册与支付宝

邮箱：复制 `deploy/mail.example.json` 到静态目录之外的私密位置，填写 SMTP 服务和发件人，使用 `password_file` 指向授权码文件。本地显式指定：

```powershell
.\scripts\start_v8.ps1 -MailConfig 'C:\private\choulema-mail.json'
```

服务器通过 `LOTTERY_MAIL_CONFIG_FILE` 读取配置，私密文件放在发布目录之外。支持校验证书的 SSL / STARTTLS。未配置 SMTP 时，免费体验和已有账号登录可用，新注册不能发码。真实收信需在目标部署环境验证。

收款：现有站点沿用支付宝应用、商户密钥、回调域名、商品价格与开关，不以示例覆盖。当前是电脑网站支付与手机网站支付。新部署按 `deploy/README.md` 配置并完成真实小额交易验收；源码包不能代替支付宝商户配置。

## 原站升级与回退

1. 新包解压到新的版本目录，建立独立虚拟环境并安装 `requirements.txt`。
2. 保留域名、生产数据库、支付宝和 SMTP 文件、`LOTTERY_CARD_SECRET` 及备份配置；不要替换为本地验收数据。
3. 维护窗口停服，确认数据库无其他写入者，再执行迁移；输出必须为不存在的新路径：

```text
python scripts/manage_db.py migrate --database /var/lib/choulema/lottery.sqlite --output /var/backups/choulema/before-feedback-唯一时间.sqlite
```

4. 迁移先备份，再检查原表原记录保留与完整性。涉及邮箱身份兼容和新反馈表；原反馈表保留，旧反馈只导入一次。
5. 生产使用专用账号、单进程 Uvicorn、外置 SQLite 和 HTTPS 反代；先通过生产启动检查，再切换服务目录。详细模板见 `deploy/`。
6. 检查健康、邮箱注册/登录、一次完整抽取、已有订单/权益、普通账号反馈、超管回复及其他账号不可读取，随后结束维护。
7. 回退代码必须继续兼容邮箱身份与当前数据；不要用旧库覆盖新增订单、账号和反馈。保留此前代码和数据库备份。

源码交付与服务器加密业务备份用途不同，后者还包含运行配置和真实业务数据。部署、备份及恢复操作需要按目标环境说明执行。
