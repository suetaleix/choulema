## 校验与再打包

交付目录同时提供 `SHA256SUMS.txt` 和交付核验报告。每个 ZIP 内的 `PACKAGE.json` 提供版本、文件清单和逐文件 SHA-256。包的 `production_approved=false` 表示打包工具不代替一次具体的生产发布审批，不否定已确认基线的部署事实。

在源码目录执行 `python scripts/package_preview.py --verify 压缩包路径` 可核验内容。存在 Git 时使用 Git 清单；解压后无 Git 时使用 `PACKAGE.json`，显式 `--include-untracked` 才包含新增的白名单源码。包不含 `.git`，有需要可由维护者自行初始化仓库。

完整测试需安装 `requirements-dev.txt` 和 Node.js；运行服务只需 `requirements.txt`。运行文件已在批准基线基础上保留，实际版本元数据为 8.0.0。底层 v6/v7 名称属于兼容路径，见 [架构说明](ARCHITECTURE.md)。
