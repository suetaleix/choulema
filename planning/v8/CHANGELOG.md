# V8.0.0 变更记录

日期：2026-10-01。基线：`7.1.0-rc.1-aurora-20261001`，该基线已由用户确认并部署。

## 2026-10-09 用户反馈本地候选

- 登录介绍页、玩法账号面板增加「问题与建议」；用户可提交并查看自己的处理进度和回复，游客也可使用。
- 超管新增反馈收件箱、筛选、回复、采纳/解决/关闭、内部备注、操作审计与总览待处理入口。
- 保留旧反馈原表，历史反馈一次性导入新收件箱；旧提交接口共用新限流，旧管理员接口保留身份字段。
- 增加请求去重、账号/浏览器归属、30 秒冷却、滚动 24 小时限额和后台并发更新校验。
- 调整反馈窗口多尺寸布局；修复音频验收脚本对中文目录的路径转换，并补齐后台模块测试依赖。
- 重复点击当前机台、主题或音效不再发起多余保存，避免短暂阻塞随后抽取。
- 后端 256 项、前端 313 项通过；实际浏览器反馈闭环、六轮机台演出、音效、四种视口与 11 个超管模块检查通过。真实邮件收件仍待用户验收。
- 运行版本暂沿用 8.0.0。未更新线上，未生成新交付包；结果详见本轮验收记录。

本轮后续交付：应用户「包呢」要求制作 `V8.0.0-20261009-feedback` 完整交付材料，详见 [交付必读](HANDOVER_20261009.md)。上述未打包状态是验收完成时的历史记录；本次交付不表示已更新线上或真实收信已验收。

## V8 整理内容

- 产品元数据、内容目录和目录请求版本统一为 8.0.0。
- 新建 `planning/v8/` 当前总规划、架构、开发任务与验收/交付入口，根 README 改为当前事实；历史记录保留。
