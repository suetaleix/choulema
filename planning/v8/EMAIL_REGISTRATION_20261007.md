# V8 邮箱注册与账号 ID 登录

确认范围：新注册只填邮箱、密码、6 位邮箱验证码，不收手机号；账号 ID 由系统自动生成。登录以邮箱为主，也可用账号 ID，老账号和权益不变；旧手机号登录接口仅保留兼容。先本地验收，未经确认不部署。

- 服务端 SMTP 加密发信，私密配置不入网页、日志、源码包。
- 验证码 10 分钟有效、60 秒重发间隔、5 次错误后作废，重发替换旧码；邮箱、IP、全站多层限流持久化。
- 数据库只保存验证码的带密钥摘要；注册、验证码消费、邀请归因和权益发放同事务，防重复注册和奖励。
- 邮箱标准化去空格、域名 IDNA、大小写一致处理；邮箱唯一，禁止头注入。不去除加号或点号，避免合并不同地址。
- 兼容迁移：phone 改为可空，新增 email / email_verified_at；保留原账号 ID、密码、会话、订单和配置，离线迁移先备份。
- 前端发送状态、倒计时、错误与重试，切换邮箱后旧验证码失效；超管可按邮箱查账号，展示邮箱验证状态。
- 不加入找回密码或邮箱更换，以免未经验证的功能被误称已交付。

## 本轮实现与验收

- 前端注册为邮箱、密码、6 位邮箱验证码三项；账号 ID 自动生成。已有账号可用 ID 登录，注册成功后自动登录进入玩法。
- 切换邮箱、切换注册/登录后，旧请求响应不能绑定到新表单；发送倒计时按邮箱分别保存。注册成功但自动登录失败时改为登录重试，不重复注册。
- 超管账号列表和权益查询以邮箱/账号 ID 展示和搜索，详情展示邮箱验证状态；历史账号显示尚未绑定邮箱。
- SMTP 私密配置已在本地独立运行目录加载，SSL 证书校验、连接与认证通过。未向未知收件人发送测试邮件，尚未验证实际收件箱投递；用户可在验收页用自己的邮箱收码注册。
- 自动化发信使用隔离收件箱替身，未对外发信。后端全量 232 项通过；之后补充启动参数与私密配置检查，相关 11 项通过（含新增 2 项）。前端全量 304 项通过。
- 覆盖邮箱标准化/重复/头注入、错误码锁定、过期、重发、挑战绑定、重放、并发单次消费、发信失败、邮箱/IP/全站持久化限流、关闭注册/维护、邀请奖励和事务回滚、已有账号 ID/旧接口、禁用账号、后台搜索。
- 旧表迁移测试包含原行、外键、索引、触发器、自增序列、失败回滚与重复执行。8911 验收库停服备份后升级，40 张原表原记录校验通过；3 个原账号保留，完整性和外键检查通过。
- 浏览器实操：注册字段、错误邮箱、短密码提示、普通账号 ID 登录进入玩法、超管 ID 登录及账号/权益详情；375×812、320×740 窄屏表单无横向溢出，输入高 46px、发码按钮 44px。
- 本地地址：http://127.0.0.1:8911/login.html 。保持独立验收库及销售关闭，未修改生产服务、支付宝或线上账号。

## 配置、限流与升级

配置方法见 [部署指南](../../deploy/README.md)。通用本地启动新增 `--mail-config` / `-MailConfig`，只接收显式私密配置，不自动继承生产设置；配置文件必须在静态目录外。示例配置不包含密码或授权码。

发码限制：同一邮箱 60 秒冷却、滚动 24 小时 5 次；同一 IP 每小时 10 次、24 小时 30 次；全站每小时 60 次、24 小时 500 次。失败发送也占额度，防止持续重试滥用。注册本身沿用同 IP 每日名额控制。持久化验证码只保存带密钥摘要，不在接口、日志或源码中输出明文验证码。

将来部署前要确认真实收件，再停服备份迁移。出现邮箱账号后，回退代码必须保留邮箱登录能力，不能用只支持手机号的旧版本直接回退。

证据目录：`artifacts/email-registration-20261007/`，包含自动化日志、本地库迁移前备份和浏览器截图；运行目录与证据均不进入交付包。
